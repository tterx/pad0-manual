# PAD0 Manual 1.0

Windows 64비트용 수동 퍼즐 경로 도우미입니다.

[실행 파일 다운로드](https://github.com/tterx/pad0-manual/releases/latest) · 릴리스의 **Assets**에서 ZIP을 받아 압축을 풀고 **PAD0Manual.exe**를 실행하세요.

- **다속성팟:** 불·물·나무·빛·어둠을 모두 매치하는 경로를 찾습니다.
- **콤보팟:** 설정한 콤보 수를 목표로 경로를 찾습니다.
- **퍼즐 인식:** 지정한 6×5 퍼즐판을 읽습니다. 내장 AI가 확신하지 못한 칸은 기존 이미지 인식 방식으로 처리합니다.
- **판 수정:** 인식된 드롭을 클릭해 수정하고, 우클릭으로 가시 여부를 바꿀 수 있습니다.
- **경로 표시·실행:** 계산한 경로를 확인한 뒤 직접 실행합니다. 조작시간·목표 콤보·회복 매치·독 회피를 설정할 수 있습니다.

### 사용 방법

1. **퍼즐판 영역 지정**으로 6×5 퍼즐판 전체를 선택합니다. 지정한 영역은 저장됩니다.
2. 게임 화면이 보이는 상태에서 **경로 계산**을 누릅니다. 현재 퍼즐판 인식부터 경로 계산·표시까지 한 번에 진행합니다.
3. 경로를 확인한 뒤 **경로 실행**을 누릅니다. 중지하려면 **중지 · 마우스 해제**를 누릅니다.

인식된 판을 직접 고쳤다면 **수정한 판 계산**을 누릅니다. 구름·암흑에 가려진 칸은 확인 후 직접 지정할 수 있습니다.

단축키도 사용할 수 있습니다: F6 경로 계산 · F8 경로 실행 · F10 중지.
